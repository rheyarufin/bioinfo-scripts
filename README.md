# Bioinformatics Scripts

Python implementations of core bioinformatics algorithms.

## Contents
All scripts are in the **Bioinformatics Algorithms/** folder:
- Frequent words, clump finding, pattern/number conversion
- Motif search (Greedy, Gibbs, Randomized)
- Approximate pattern matching, GC skew, Hamming distance, and more

## Usage
python ScriptName.py
